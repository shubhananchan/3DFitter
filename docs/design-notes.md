

## Gap split
The gap is split evenly between the hole and the peg. Both parts stay close to the nominal size in CAD, and hole minus peg equals the fit's total gap. The printer offset corrects printer error separately.

## Gap values
Press 0.05, snug 0.10, slide 0.20, loose 0.40 mm total clearance. Starting points from common FDM clearance guidance, to be tuned with test prints.
